## 待決定的項目

大堡礁、Steve Irwin、喙頭蜥、Waitangi、帝王斑蝶、Benito Juárez、德國香腸…),另有些項目本來就沒附圖。

- **做法**:派一個 subagent 專門重找這些主題的 Commons 合規圖 → 跑現有產線補上。純執行,無分岔。
- **要你決定**:無 —— 你點頭我就跑(約 1 個 subagent + 1 次產線)。

### ⑤ 熱門 + 冷門旅遊行程(加強)

現況:`recommended` 每國 2–3 條,一句話。

- **提案**:大百科新增「行程建議」區塊,分兩類:
  - **熱門路線** 4–5 條:每條「路線名 · 約 N 天 · 2–3 句(去哪、看什麼、適合誰)」。
  - **私房 / 冷門** 3 條:每條「主題 · 2 句(為什麼值得、注意什麼)」。
  - schema:`itineraries: { hot: [{title, days, note}], niche: [{title, note}] }`。
- **要你決定**:
  - (a) 深度:上述「路線名 + 幾句」就好,還是要**逐日行程**(D1/D2/D3…,內容量大很多)?→ 建議前者。
  - (b) 派 subagent 分批補內容(和大百科同模式)。點頭即做。

### ⑥ 台灣旅行社行程 + 價格比較 + 連結

**這項有硬限制**:旅行社套裝行程的價格天天在變,雄獅 / 可樂 / 東南 / 山富 / KKday / Klook / 易遊網
的頁面爬取違反使用條款、且抓下來的價格隔週就過時。真正「即時比價」需要付費 API + 長期維護,
對個人專案不划算。

- **提案 A(建議)—— 只做「一鍵搜尋」連結**:每國一排按鈕「在雄獅搜尋日本 / 在 KKday 搜尋日本 / …」,
  連到各家該國搜尋結果頁(永遠是最新的,不爬價格)。使用者到各家網站自己比價。
- **提案 B —— 靜態快照**:建置時由 subagent 抓幾筆代表性行程(名稱 + 價格 + 連結)寫死。
  幾週就過時,要定期重抓。誠實度低。
- **提案 C —— 不做**。
- **要你決定**:A / B / C?若 A,要放哪幾家旅行社?(建議:雄獅、可樂、東南、KKday、Klook)

### ⑦ 各國縣市地圖 + 縣市行程(願景:「全能地球細分到城鎮」)

這是 Wave C 最大的一塊,等於一個新子系統。

- **資料**:Natural Earth `ne_10m_admin_1_states_provinces`(公有領域)有全球一級行政區
  (縣/州/省)多邊形。每國 5–50 個。
- **呈現方式(要你決定)**:
  - **A —— 大百科頁裡的 2D 地圖**:該國一級行政區的平面地圖,標所有縣市名、首都用不同標記,
    點縣市 → 顯示該縣市的簡介 / 特色 / 推薦。工程量中等,先做得出來。
  - **B —— 直接在 3D 地球上**:放大到該國時疊上縣市邊界 + 標籤,點縣市互動。更符合「全能地球」
    願景,但標籤管理、點擊、鏡頭都要大改,工程量大很多。
  - 建議:**先 A(先做 臺灣 + 日本 + 美國 三國驗證版面與資料),Phase 2 再做 B。**
- **每個縣市的內容**:20 國 × 平均 ~20 區 = ~400 個區域。「名稱 + 1–2 句特色 + 1 條推薦」是可行量級;
  「每個縣市都做迷你大百科」則是另一個 20-國規模的工程。
- **要你決定**:
  - (a) A 還是 B 先做?
  - (b) 先做哪幾國(臺灣優先?還是 20 國一起)?
  - (c) 每個縣市內容深度(名稱+一句 vs 迷你條目)?

### 美術方向 —— 大百科視覺升級 + 動畫

現況:深色玻璃感 UI,功能取向。你想要水彩 / 電影 / 科幻 / 旅遊風 + 動畫。

- **提案:做成「可切換主題」**(像背景音樂那樣),先給 2 種:
  - **「深空」**(目前這套,保留)。
  - **「旅誌」(建議主打)**:暖色調、米白紙質背景、標題用襯線字、水彩暈染點綴、大圖排版、
    捲動時區塊淡入 / 上滑(IntersectionObserver)。比科幻風更適合百科 / 旅遊內容。
  - (可選)**「院線」**:高對比、上下黑邊、進場推移動畫。
- **捲動淡入動畫**:不分主題都加(尊重 `prefers-reduced-motion`)。
- **要你決定**:
  - (a) 要幾種主題?主打哪一種?
  - (b) 「旅誌」風 OK 嗎,還是你要科幻 / 電影風當主打?
  - (c) 有沒有想參考的具體網站 / 作品?
